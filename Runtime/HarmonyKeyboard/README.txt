HUStudio Unity keyboard and message bridge
=============================================

The bridge is included in the HUStudio UPM or unitypackage distribution.
For UGUI InputField, add HarmonyKeyboardBridge to the same GameObject.
Unity to HarmonyOS messages use HarmonyMessageBridge.UnityToNative(string).
See the Quick Start sample for a complete scene and the HarmonyOS / 环境与导出
window for the WebGL to HAP workflow.
