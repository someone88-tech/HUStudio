# HUStudio HarmonyOS Unity SDK

Unity 的 HarmonyOS 导出插件。先检测 DevEco 环境，再构建 WebGL，最后导出 DevEco 工程或 HAP。  
Unity HarmonyOS exporter. Check DevEco, build WebGL, then export a DevEco project or HAP.
