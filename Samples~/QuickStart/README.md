# Quick Start 示例 / Sample

导入 Sample 后，打开 `Scenes/HarmonyDemoScene.unity`。场景演示 Unity 与原生消息、HTTP/WebSocket、存储、Worker、音频和中文输入。它使用主包 Runtime 中的 `HarmonyKeyboardBridge`。自己的工程通过 **HarmonyOS / 环境与导出...** 构建，示例场景不是导出的必需内容。详细步骤见 [中文教程](../../Documentation~/GettingStarted.zh-CN.md)。

After importing the sample, open `Scenes/HarmonyDemoScene.unity`. It demonstrates Unity/native messaging, HTTP/WebSocket, storage, Worker, audio, and Chinese keyboard input. It uses `HarmonyKeyboardBridge` from the package Runtime folder. Build your own scenes through **HarmonyOS / 环境与导出...**; the sample scene is optional. See the [English guide](../../Documentation~/GettingStarted.en.md).
